about=A geotechnical tool for 2D slope stability analysis inside QGIS, inspired by the feature set of XSLOPE. Methods of slices: Ordinary (Fellenius), Bishop simplified, Janbu simplified (with f0 correction), Corps of Engineers #1 and #2, Lowe-Karafiath, Spencer and Morgenstern-Price. Critical surface search: circular grid search, circular entry-exit search, non-circular path search, Nelder-Mead and vertex optimisation, user-defined surfaces, and crack point analysis (pick a crack on the ground and analyse slip surfaces starting there). Inputs drawn as QGIS layers in section coordinates (x = distance, y = elevation): multi-material geology polygons (Mohr-Coulomb, undrained Su, Hoek-Brown), piezometric line or ru, distributed surcharge, tension crack with water, pseudo-static seismic loading (kh, kv), reinforcement (geogrids, nails, anchors with pull-out) and piles / retaining walls. Parametric scan of kh and water table depth, Monte Carlo and Taylor series reliability analysis, HTML report, styled GeoPackage results and a Processing algorithm for batch and model use. The interface and report follow the QGIS language (English, Traditional Chinese, Simplified Chinese, Japanese, Korean, Spanish, French, German, Portuguese). Requires numpy and shapely, which are included in the standard QGIS installers. Earlier versions were developed with the assistance of Gemini; version 3 was developed with the assistance of Claude.

    3.1.0

    3.0.0

    * Circular grid and entry-exit searches with Nelder-Mead optimisation; non-circular path search with surface optimisation; user-defined surfaces
    * Strength models: Mohr-Coulomb, undrained (Su), Hoek-Brown; saturated unit weight; ru
    * Distributed loads, tension crack (with water), kv, reinforcement with pull-out, piles / walls (active or passive)
    * Parametric scan (replaces the v2 General Scan), Monte Carlo and Taylor series reliability
    * Slice layer, search-centre layer, FS-classified styling, HTML report with cross-section
    * Processing algorithm for batch processing and the Model Designer
    * Multi-language interface (9 languages) following the QGIS locale
    * Compatible with QGIS 3.28+ and QGIS 4 (Qt5 / Qt6)
