QGIS 邊坡穩定分析 3.0 – 使用說明

在 QGIS 內進行二維極限平衡邊坡穩定分析。模型以一般 QGIS 圖層繪製於剖面坐標：x = 水平距離、y = 高程，單位皆為公尺。

1. 快速開始

  1. 外掛 ▸ 邊坡穩定分析 ▸ 載入範例資料：加入兩層地質模型、地下水位線、擋土牆、分布載重（建築物 q = 25 kPa、道路 q = 12 kPa）、四支土釘（T = 180 kN/m、拉拔阻抗 45 kN/m/m）及兩條使用者自訂滑動面（圓弧與軟弱層路徑）。在對話框中選取對應圖層即可試用各項功能。
  2. 開啟 邊坡穩定分析…，選擇地質圖層（可另選地下水位線），按 檢查輸入，再按 執行分析。
  3. 成果會加入新的圖層群組：臨界滑動面（標示 FS）、依 FS 分色的滑動面、臨界滑動面切片、搜尋格網圓心；並在瀏覽器開啟 HTML 報告。

2. 輸入圖層

圖層幾何欄位（不分大小寫）
地質 / 材料 （必要）面unit_weight（kN/m³）、cohesion（kPa）、phi（°）為必要欄位。
選填：name/layer_name、unit_weight_sat（飽和單位重）、model（mc、undrained、hb、none）、Hoek-Brown 參數 sigci（kPa）、gsi、mi、d；ru；piezo（0 = 此材料不套用地下水位線）；可靠度分析用 c_std、phi_std、gamma_std。
地下水位線線–（u = γw × 至水位線的垂直距離；地表以上的積水以地表水壓作用）
分布載重線q（kPa，垂直，作用於線的水平範圍）
加勁材線T 抗拉強度（kN/m）、pullout（滑動面後方每公尺拉拔阻抗，0 = 不限制）、mode（passive 被動 / active 主動）
樁 / 擋土牆任意V 抗剪力（kN/m）、mode。於滑動面切過該圖徵處作用。
使用者自訂滑動面線– 每條線皆會分析；圓弧會自動辨識為圓。

載重、加勁材、樁圖層缺少欄位時，採用「載重與支撐」分頁的預設值。2.x 版的欄位（cohesion、phi、unit_weight）可直接沿用。

3. 分析設定

切片法

方法平衡條件切片間力假設
瑞典法（Fellenius）力矩忽略（僅圓弧）
Bishop 簡化法力矩水平（僅圓弧）
Janbu 簡化法水平力水平，含修正係數 f0
美國陸軍工兵團法 #1 / #2力平行於進出點連線 / 地表
Lowe-Karafiath力地表與滑動面坡度平均
Spencer力矩 + 力固定傾角（λ）
Morgenstern-Price力矩 + 力λ·f(x)，半正弦函數

搜尋所用方法用來計算每個試算滑動面；找到臨界滑動面後，再以所有勾選的方法計算。

滑動面搜尋

  • 圓弧 - 格網搜尋：圓心格網 × 切線（深度）層次，再以 Nelder-Mead 最佳化 (x, y, R)。
  • 圓弧 - 進入點與滑出點：通過坡頂進入點與坡趾滑出點的圓弧。
  • 非圓弧 - 路徑搜尋：隨機產生符合運動條件的路徑（下凹、滑出角不陡於 45°），再進行節點最佳化。若選擇僅適用圓弧的方法，將改用 Spencer。
  • 僅分析使用者自訂滑動面。
  • 由地圖點選的裂隙點：見第 3a 節。

搜尋密度 100 % 約 3,500 個圓弧（格網搜尋）。滑動方向自動判斷。預設忽略端點位於模型左右邊界的滑動面（若臨界面碰到邊界，請加大模型範圍）。

3a. 裂隙點分析

當現場地表發現張力裂隙或崩崖，想評估由該處開始滑動的安全係數時使用。

  1. 按工具列按鈕 點選裂隙點並分析…（或在對話框中：分析設定 ▸ 滑動面型式 ▸ 由地圖點選的裂隙點 ▸ 在地圖上點選）。
  2. 在剖面圖上點選裂隙所在的地表位置。只使用 x 坐標，點會垂直投影至地表。按右鍵或 Esc 取消。
  3. 對話框開啟並已填入點位，執行分析即可。

所有試算滑動面皆由裂隙點開始並向下坡延伸：包括通過裂隙點與各可能滑出點的圓弧，以及由裂隙點出發的隨機非圓弧路徑；最佳者再於固定進入點的條件下最佳化。圓弧面使用「搜尋所用方法」，非圓弧面在該方法僅適用圓弧時改用 Spencer。臨界滑動面、所有保留的滑動面及 crack_point 標記圖層會加入地圖。可搭配「張力裂縫」深度模擬張開（必要時充水）的裂縫。

情境

參數掃描取代 v2 的「通用矩陣掃描」：kh 值與地下水位深度（與地表平行，dry = 無水）的每種組合都會搜尋，並以情境名稱儲存（例如 Scan_Kh0.1_D15m）。

可靠度

材料若有 c_std、phi_std 或 gamma_std，將對主要分析的臨界滑動面進行蒙地卡羅模擬（常態分布）與泰勒級數法（FS 對數常態，Duncan 2000）。報告列出破壞機率 Pf、可靠度指標 β 及各變數的變異數貢獻比例。

4. 輸出成果

圖層內容
critical_surface各情境的臨界滑動面，含所有方法的 FS、λ（Spencer、M-P）、圓心、半徑、進出點。
slip_surfacesFS 最低的滑動面（預設每情境 300 條），分級顏色：<1.0 紅、1.0–1.2 橘、1.2–1.5 黃、1.5–2.0 淺綠、>2.0 綠。
slices臨界滑動面切片：重量、α、c、φ、u、N′、σ′n、發揮剪力。
crack_point點選的裂隙點及其最小 FS（僅裂隙點分析）。
search_centers各格網圓心的最小 FS（預設隱藏，可製作 FS 等值線）。

GeoPackage 路徑留空則產生暫存圖層。本分析也可在 處理工具箱 ▸ Slope Stability 中使用（批次處理、模型設計器）。

5. 語言

介面與報告語言依 QGIS 介面語言（設定 ▸ 選項 ▸ 一般 ▸ 使用者介面翻譯）自動切換：English、繁體中文、简体中文、日本語、한국어、Español、Français、Deutsch、Português；也可在「輸出」分頁手動指定。

6. 限制

  • 二維極限平衡、平面應變、單位寬度。尚未提供有限元素滲流與強度折減法（規劃中）。
  • 孔隙水壓僅由地下水位線或 ru 計算（無滲流分析、無急速洩降）。
  • 地質多邊形應共用邊界、無空隙或重疊（「檢查輸入」會提出警告）。

分析成果須由合格工程師審核。本程式已以 ACADS 範例 1(a)（Bishop 0.985、Spencer 0.984；參考值約 0.99–1.00）、無限邊坡（乾燥、地震、滲流）及 Taylor 不排水垂直開挖驗證。
